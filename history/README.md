# History archive

`history/` 保存已停止作为当前主线推进的模型家族，用来回答“我们试过什么、为什么没有继续”。它们不是默认运行入口，也不保证与当前数据路径或依赖版本完全兼容。

| 目录 | 角色 |
| --- | --- |
| `attention/` | 早期注意力模型 |
| `cnn/` | 早期一维/卷积路线 |
| `cnn2d_mlp/` | 将响应组织为空间张量的混合路线 |
| `unet_mlp/` | U-Net 风格空间编码路线 |

每个子目录保留自己的 README 和 Log。若要复跑，应先核对数据格式、随机种子和依赖，不要把历史输出直接与当前 GNN 指标拼成排行榜。
