# GNN_EXPAND Data

本目录保存 `GNN_EXPAND` 的四套原生拓扑 clean 数据：
- `square_10x10.csv`
- `rect_6x10.csv`
- `honeycomb_63.csv`
- `circlecut_69.csv`

每套数据都配有对应 meta：
- `*_meta.json`

## 生成规则
- 统一由：
  - `gnn/GNN_EXPAND/generate_expand_datasets.py`
  直接在目标拓扑上做基尔霍夫线性系统正演求解生成。
- 统一默认：
  - `total_combos=10000`
  - `current_source_a=0.01`
  - `change_count_ratio = 0.07 / 0.31 / 0.31 / 0.31`
  - `change_ratio_range = [0.05, 0.30]`

## 重要约束
- 激励只使用外部节点。
- 测量只输出外部节点电压。
- 每套数据均固定 `28` 个外部节点、`32` 组激励：
  - 28 组顺时针相邻边界激励
  - 4 组额外跨边界激励

## 当前用途
- 四个阶段目录默认都切换为读取本目录内对应的原生数据。
- `GNN_EXPAND/common` 仍保留旧的拓扑映射逻辑，便于兼容根目录老数据，但默认训练入口已优先使用这里的新数据。
## 2026-04-02 更正
- 先前把四套 `EXPAND` 数据统一写成 `28` 个外部节点、`32` 组激励，这个口径不对。
- `GNN_EXPAND` 的原生数据生成规则是：
  - 激励只使用外部节点
  - 测量只输出外部节点电压
  - 外部节点数和激励组数都按目标拓扑自己的边界规模确定，不再强行对齐 `8x8`
- 当前四套数据的真实规模为：
  - `square_10x10`: `36` 个外部节点，`40` 组激励
  - `rect_6x10`: `28` 个外部节点，`32` 组激励
  - `honeycomb_63`: `28` 个外部节点，`32` 组激励
  - `circlecut_69`: `24` 个外部节点，`28` 组激励
