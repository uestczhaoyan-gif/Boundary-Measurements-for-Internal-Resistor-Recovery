## 当前状态摘要

### 问题定义

- 拓扑：正方形 `N x N`
- 已完成规模：`N=3,4,5`
- 已完成 `K`：`1..6`
- 基准电阻：`1000 Ω`
- 变化范围：`±20%`
- 无噪声
- 固定 `K`，不做数量分类
- 成功标准：
  - `id_exact_rate >= 0.98`
  - `value_accuracy >= 0.90`

### 数据

- 每个 `(N, K)` 都有独立数据集
- 样本数：train `8000` / val `1000` / test `1000`
- 数据由**直接解基尔霍夫方程**生成
- 默认激励为**顺时针边界相邻循环激励**

### 模型状态

- `modelv1`：最简纯回归，`SmoothL1Loss`，推理时按 `|pred|` 取 top-`K`
- `modelv1_1`：只改损失，变化边/未变化边加权 SmoothL1
- `modelv2`：score head + value head，ranking loss + 加权 SmoothL1

## 关键结论

### `modelv1`

- `N=3 (P=8)`：`K_max = 1`
- `N=4 (P=12)`：`K_max = 1`
- `N=5 (P=16)`：严格标准下 `K_max = 0`

结论：

- `value_accuracy` 普遍较高
- 主要瓶颈是 `id_exact_rate`
- 说明问题出在 support 恢复，而不是数值回归本身

### `modelv2`

- `N=3 (P=8)`：`K_max = 1`
- `N=4 (P=12)`：`K_max = 0`
- `N=5 (P=16)`：`K_max = 1`

结论：

- 数值精度多数情况下比 `modelv1` 更高
- 但 `id_exact_rate` 没有整体提升，很多点反而更差
- 当前“更复杂的头 + ranking loss”并没有自动转化为更强的样本级精确 support 恢复率

## 下一步建议

- 先不要继续扩大规模扫描
- 先固定在 `3x3`
- 优先尝试更简单、更直接服务于 support 恢复的结构
- 避免继续堆叠太深的图注意力和跨激励复杂模块
