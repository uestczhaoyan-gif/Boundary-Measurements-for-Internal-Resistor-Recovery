# 电阻组合可辨识性研究计划

## 1. 研究动机

现有工作主要回答“在给定规模和端口条件下，最多能识别多少个变化电阻”。老师进一步关注的是：

**当实际变化电阻数 `R >= 2` 时，不同电阻组合本身是否存在可识别性差异。**

这个问题直接对应光学编码策略：如果某些电阻组合更容易被识别，则可以优先把光强、位置、偏振、波长等光学信息编码到这些组合上；如果某些组合容易混淆，则应避免作为关键编码通道。

## 2. 符号约定

- `N`：正方形网络规模，即 `N x N` 节点网格。
- `P`：边界端口数量。
- `M`：网络总电阻数量。
- `C`：候选可变电阻池大小，即允许发生变化的电阻集合。
- `R`：单个样本中真实变化的电阻数量。
- `R_max`：给定精度阈值下最大可稳定识别的变化电阻数量。

本子项目默认从 `R = 2` 开始，因为两电阻组合已经能体现“组合关系”和“混淆关系”。

## 3. 阶段计划

### Phase 1. 物理灵敏度初筛

目的：不训练新模型，先从正向电路响应判断哪些电阻组合可能更容易或更困难。

做法：

- 固定 `N = 4` 或 `N = 5`。
- 固定候选池 `C`，首版默认使用全电阻候选池。
- 对每条候选电阻单独施加微小扰动，计算边界电压响应变化向量。
- 对任意两条电阻组合 `(i, j)` 计算：
  - 单边灵敏度强度。
  - 两条边响应向量余弦相似度。
  - 同向变化响应强度 `||s_i + s_j||`。
  - 反向变化响应强度 `||s_i - s_j||`。
  - 最弱组合响应强度 `min(||s_i + s_j||, ||s_i - s_j||)`。

基本判断：

- 响应强、相似度低的组合更容易识别。
- 响应弱、相似度高的组合更容易混淆。
- 若反向变化导致响应抵消，则该组合在某些符号组合下更困难。

### Phase 2. 模型推理分组验证

目的：验证物理灵敏度初筛是否能预测模型实际识别难度。

做法：

- 按 Phase 1 的 easy score 将组合分为：
  - 易识别组合组。
  - 中等组合组。
  - 困难组合组。
- 使用同一个已训练模型分别在三类组合测试集上推理。
- 比较：
  - 位置识别准确率。
  - 数值回归精度。
  - Top-R 排序间隔。
  - 常见混淆组合。

### Phase 3. 组合数据集与平衡验证

目的：排除训练样本分布不均衡带来的误差。

做法：

- 为每个两电阻组合生成相同数量样本。
- 固定每个组合的变化幅值分布。
- 重新构建平衡测试集，必要时构建平衡训练集。
- 对比模型在不同组合上的表现是否仍存在稳定差异。

### Phase 4. 汇报图与编码建议

最终输出：

- 组合难度散点图。
- 易识别/困难组合在拓扑上的示意图。
- 组合类别与模型识别准确率对比图。
- 面向光学编码的建议：优先使用哪些组合，避免哪些组合。

## 4. 首版验收标准

- 对 `N=4, C=24, R=2` 完成全部组合物理灵敏度排序。
- 输出组合指标 CSV。
- 输出组合难度散点图。
- 输出 Top easy / Top hard 组合拓扑示意图。
- 给出下一步模型推理验证所需的组合列表。
