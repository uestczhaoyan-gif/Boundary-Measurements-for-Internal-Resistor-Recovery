# 电阻组合可辨识性子项目

本子项目用于研究老师新关注的问题：

**在固定网络规模、固定实际变化电阻数量 `R >= 2` 的条件下，不同变化电阻组合是否具有不同的可识别难度。**

如果某些电阻组合天然更容易被模型稳定识别，则后续光学信息编码可以优先映射到这些“易识别组合”上；如果某些组合容易混淆，则应避免把关键信息编码到这些组合上。

## 核心问题

- 固定正方形拓扑，例如 `4x4` 或 `5x5`。
- 固定候选可变电阻池 `C`。
- 固定实际变化电阻数量 `R = 2`。
- 枚举或采样所有两电阻组合。
- 判断哪些组合更容易识别，哪些组合更困难。

## 目录结构

- `README.md`：子项目入口说明。
- `PLAN.md`：研究计划、阶段划分和指标定义。
- `LOG.md`：实验记录和阶段性结论。
- `scripts/`：组合分析、数据生成、模型推理统计和画图脚本。
- `data/`：后续按组合或组合分组生成的数据。
- `outputs/`：组合指标表、排序结果、模型推理统计结果。
- `Figure/`：最终汇报图。

## 当前实现

当前已实现第一步物理分析脚本：

```powershell
python square_scale_study\combo_identifiability\scripts\analyze_pair_sensitivity.py --grid-size 4 --candidate-count 24
```

它会对候选池内所有两电阻组合计算：

- 单边电压响应灵敏度强度。
- 两条电阻响应模式的余弦相似度。
- 同向/反向变化下的组合响应强度。
- 简单的组合易识别评分。

输出文件默认位于：

- `combo_identifiability/outputs/`
- `combo_identifiability/Figure/`
