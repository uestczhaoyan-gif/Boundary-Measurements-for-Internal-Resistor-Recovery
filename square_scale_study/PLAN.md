# `square_scale_study` 计划书

## 总体目标

`square_scale_study` 是与已冻结 `gnn` 主线解耦的独立子项目。它只研究一个问题：

**在固定正方形拓扑下，最大可识别同时变化电阻数量 `K_max` 如何随端口数/规模变化？**

主线研究设定为：

- 只使用正方形网格：`3x3` 到 `10x10`
- 每个数据集固定变化数量 `K`
- 只研究回归，不做数量分类
- 不加噪声
- 变化电阻位置随机
- 电阻变化范围为 `±20%`

主结果曲线定义为：

- 横轴：端口数 `P = 4N - 4`
- 纵轴：最大可识别变化数量 `K_max`

## 第一阶段：固定问题定义与判据

固定设定如下：

- 拓扑：正方形 `N x N`，其中 `N = 3, 4, 5, 6, 7, 8, 9, 10`
- 节点数：`N^2`
- 电阻边数：`M = 2N(N - 1)`
- 端口数：`P = 4N - 4`
- 每个数据集固定一个 `K`
- 不混合不同 `K` 训练
- 不做变化数量分类
- 基准电阻：`R0 = 1000 Ω`
- 不加入测量噪声
- 每个样本中的变化边随机抽取且不重复
- 默认激励方式：沿顺时针边界节点做相邻循环激励，总激励数等于 `P`

通过判据固定为两项，同时满足才算“可识别”：

- `id` 判据：样本级精确 support 恢复率 `>= 0.98`
- 数值判据：
  - `value_accuracy = max(0, 1 - MAE_changed / (0.2 * R0))`
  - 阈值 `>= 0.90`

定义：

- `K_max(N)` 表示在规模 `N` 下，测试集同时满足上述两项判据的最大 `K`

## 第二阶段：建立固定 `K` 数据生成器

新数据集不再复用旧项目里混合 `0/1/2/3` 变化数量的格式。

生成规则：

- 每个 `(N, K)` 都有独立数据集
- 每个样本恰好包含 `K` 条变化电阻
- 变化边从全部电阻边中随机采样
- 变化值按 `R = R0 * (1 + δ)` 采样，其中 `δ` 在 `[-0.2, 0) ∪ (0, 0.2]` 上均匀分布
- 每个样本都在默认全边界激励集合下直接解基尔霍夫方程
- 基线电压由全 `R0` 网络求得，再相减形成电压扰动
- 图输入保持四类节点特征：
  - source mask
  - ground mask
  - 边界电压扰动
  - 边界节点 mask

默认数据划分：

- train: `8000`
- val: `1000`
- test: `1000`

命名规则：

- `data/N3x3/`, `data/N4x4/`, ..., `data/N10x10/`
- 每个数据集保存为：
  - `square_N3x3_K1_train.csv`
  - `square_N3x3_K1_val.csv`
  - `square_N3x3_K1_test.csv`
  - `square_N3x3_K1_meta.json`

## 第三阶段：最简回归主线

第一版模型刻意保持简单。

固定模型/训练设定：

- 只做回归
- 复用当前 GNN 主线的基本思想：
  - 每个激励图内做消息传递
  - 跨激励做注意力池化
  - 最后输出边级回归值
- 不使用 mask head
- 不使用门控
- 不输出候选集
- 不使用 BCE、稀疏正则或对比损失
- 第一版损失为 `SmoothL1Loss(pred, target)`
- 推理时按 `|pred|` 选择前 `K` 条边

checkpoint 排序规则：

1. `val_id_exact_rate`
2. `val_value_accuracy`
3. `-val_mae_changed`

每个 epoch 至少保留：

- `train_id_exact_rate`
- `train_value_accuracy`
- `val_id_exact_rate`
- `val_value_accuracy`
- `val_mae_changed`

## 第四阶段：扫描 `(N, K)` 得到主曲线

主线扫表策略：

- 对每个 `N`，从 `K = 1` 开始
- 每个 `(N, K)` 都独立生成、独立训练、独立推理
- 若测试集满足：
  - `test_id_exact_rate >= 0.98`
  - `test_value_accuracy >= 0.90`
  则记为通过，并继续测试 `K + 1`
- 某个 `K` 首次失败后，再多测一个 `K`
- 连续两个 `K` 失败后，停止该规模扫描
- 最后一个通过的 `K` 记为 `K_max`

每个 `(N, K)` 都必须保留：

- 训练侧：
  - `train_id_exact_rate`
  - `train_value_accuracy`
- 推理侧：
  - `test_id_exact_rate`
  - `test_value_accuracy`
- 辅助信息：
  - `val_id_exact_rate`
  - `val_value_accuracy`
  - `test_mae_changed`
  - `pass_flag`

必须输出：

- 明细表：每个 `(N, K)` 的训练/验证/测试指标
- 汇总表：`N`、`P`、`M`、`K_max` 及对应测试指标
- 主图：
  - `N` vs `K_max`
  - `P` vs `K_max`

## 第五阶段：多激励研究（主工作之后）

这一阶段明确后置，只有在主曲线稳定后才进入。

研究问题：

- 多激励组合是否真的增加了可用信息通道数？
- 还是主要提升了数值精度和稳定性？

代表性规模：

- `N = 4, 7, 10`
- 每个规模选：
  - `K = K_max(N) - 1`
  - `K = K_max(N)`

要比较的激励子集：

- `1`
- `2`
- `4`
- `8`
- `full`

数值分析输出：

- `test_id_exact_rate`
- `test_value_accuracy`
- `test_mae_changed`
- `K_max` 是否改变

物理分析输出：

- 响应矩阵秩 / 有效秩
- 奇异值谱
- 条件数
- 不同激励集合下的响应相似性 / 相干性

结论判据：

- 若激励数增加导致 `K_max` 上升，说明其提升了可辨识信息
- 若 `K_max` 不变但误差下降，说明其主要提升了精度或稳定性
- 若两者同时发生，则需分开报告“信息增益”和“稳定化效应”

## 2026-04-28 新增方向：组合级可辨识性

老师进一步关注的问题是：在固定规模、固定候选池、固定实际变化电阻数 `R >= 2` 时，不同变化电阻组合是否有不同识别难度。

该方向不替代前面 `P`、`C`、`R_max` 主线，而是面向光学编码应用的进一步细化：如果某些组合更容易稳定识别，则可优先将光学信息编码到这些组合；如果某些组合天然容易混淆，则应避免作为关键编码通道。

对应子目录：

- `combo_identifiability/`

阶段安排：

- 先做 `R = 2` 的组合物理灵敏度初筛。
- 再按 easy / hard 组合生成平衡测试集。
- 最后用同一个模型验证不同组合类别的实际识别准确率差异。

## 2026-04-13 新增要求（师兄反馈纳入计划）

本节用于记录当前主线之外新增的约束条件。后续实现、汇报和结果解释都以这里为准，不再临时改口。

### A. 统一模型优先

- 主问题的理想目标仍然是：**尽量使用同一类模型完成不同规模 `N` 下的 `K_max` 判断**
- 后续所有模型迭代，优先考虑“能否成为跨规模统一参考模型”，而不只是“某个单点 `(N, K)` 是否更高”
- 现阶段由于模型还不稳定，短期上仍允许先在 `N=3` 上快速试错；但一旦出现明显更优方案，后续要尽快验证它是否能迁移到更大规模

### B. 自适应模型只能作为次级方案

- 如果后续证明不存在一套在所有规模下都足够稳健的统一模型，则允许采用“按规模选择不同模型”的工程方案
- 但这种方案必须满足两个条件：
  - 选择规则必须预先固定，不能事后按结果挑最好模型
  - 汇报时必须明确说明：这是“自适应模型族”，不是“单一统一模型”
- 因此后续若走自适应路线，需要单独记录“哪个规模使用哪个模型”的固定规则

### C. 评价阈值允许解释性调整

- 目前默认通过标准仍保持：
  - `id_exact_rate >= 0.98`
  - `value_accuracy >= 0.90`
- 但该阈值不再视为不可变硬规则
- 当前约定的首轮阈值组为：
  - `0.98`
  - `0.95`
  - `0.90`
  - `0.85`
- 这些阈值默认都作用于 `id_exact_rate`
- 多阈值分析只影响训练后的：
  - `K_max` 判定
  - 汇总表
  - 对比图和可视化
- 多阈值分析**不改变训练过程本身**
- 后续允许增加“阈值敏感性分析”，比较不同阈值下的 `K_max`、曲线形状和结论稳定性
- 若最终采用低于 `0.98` 的阈值，必须同步给出理由：
  - 为什么这个阈值更符合“可识别”的物理或工程定义
  - 调整阈值后主结论是否发生本质变化

### D. 需要正式分析模型差异，而不是只报最好结果

- 后续不能只报告“哪个模型分数最高”
- 必须同步分析：
  - 不同模型在同一 `N` 下差异是否显著
  - 差异主要来自主干结构，还是来自 loss 设计
  - 训练集、验证集、测试集三侧差异分别说明什么
- 当前已明确的一条分析原则是：
  - 若纯 `MSE` 版本持续优于 support-aware 版本，应优先解释为“loss 设计影响更大”，而不能简单下结论说“GNN 不如 MLP”或“MLP 不如 GNN”

### E. 主指标与辅助诊断指标分工

- 当前主指标仍保持两项：
  - `id_exact_rate`
  - `value_accuracy`
- 现阶段项目判断 `K_max` 时，仍以这两项为正式判据
- 其中阈值敏感性分析主要围绕 `id_exact_rate` 展开，因为当前各模型的 `value_accuracy` 普遍较高、区分度较小
- 针对“位置预测错了，但未变化位置却被预测成很大电阻变化”这一担忧，后续允许增加辅助诊断指标，例如：
  - 未变化边上的平均误报幅值
  - 未变化边上的最大误报幅值
- 这些辅助指标的作用是帮助解释错误机理，而不是立即替代当前主判据

### F. 外部端口更多但结果更好的现象要作为正式问题记录

- 后续要把“规模更大/外部端口更多时，结果反而可能优于更小规模”视为一个需要专门解释的现象
- 暂定从两个层面分析：
  - 物理层面：端口与激励数增多是否确实提供了更多独立观测信息
  - 学习层面：不同规模下模型容量、优化难度和样本分布是否改变了结果
- 在没有统一模型控制前，不把这种现象直接解释成纯物理规律

### G. 增加一个受控协议：边界-边界电阻固定不变

- 后续增加一个新的对照协议：
  - 默认主协议仍允许所有边变化
  - 新协议中，**边界节点之间的电阻边不允许变化**
- 该协议的作用不是替代主协议，而是回答：
  - 若去掉最靠近测量端口的一类边，`K_max` 会提高还是降低
  - 当前难度是否主要来自候选边数太大，还是来自内部边本身更难辨识
- 该协议必须作为“第二套评估口径”单独保存，不能与主协议结果混合

- 记 `M_var` 为“允许变化的候选电阻总数”
- 注意：
  - 这不是每个样本里真实变化的条数
  - 每个样本里真实变化条数仍然是固定的 `K`

## 2026-04-19：子项目 5 立项：深度对可识别性的影响

该子项目用于回答一个更细的结构性问题：

- 在固定拓扑、固定边界激励/测量协议下，靠近边界的电阻是否比更靠内部的电阻更容易被识别？

当前先不直接上多变化组合，而是先把“深度效应”本身做干净。

### 一、核心研究问题

希望判断以下规律是否成立：

- 外层电阻更容易被预测，内层电阻更难被预测
- 这种“由外到内”的难度变化是否会随着规模增大而更明显

若该规律成立，它将成为解释“为什么同样的 `K` 在不同拓扑位置难度不同”的直接证据。

### 二、第一阶段：快速验证版

快速验证版只做最小控制变量实验：

- 规模固定为：
  - `4x4`
  - `5x5`
- 每个样本固定：
  - `K = 1`
- 激励与测量协议保持不变：
  - 仍然只允许边界节点作为激励端口
  - 仍然只读取边界节点电压作为测量
- 模型固定为当前统一参考 `GNN`：
  - `modelg2`

这样做的原因是：

- 若直接上 `K > 1`，误差会混入多变化边之间的组合混淆
- 先做 `K = 1`，才能把“深度效应”和“多目标干扰效应”分开

### 三、深度定义

节点深度定义为其到边界的最小网格步数：

- `depth(node) = min(r, c, N-1-r, N-1-c)`

电阻边深度默认定义为其两个端点深度的较小值：

- `depth(edge) = min(depth(u), depth(v))`

在该定义下：

- `depth = 0` 表示贴近边界的外层电阻
- `depth = 1` 表示更靠内部的一层电阻

对于 `4x4` 与 `5x5`，当前重点不是追求很多层，而是先检验：

- 外层 vs 内层

### 四、第二阶段：正式平衡采样版

若快速验证版已经显示出“外层明显优于内层”，则进入正式实验。

正式实验的关键改动是：

- 不再只按全体电阻随机采样变化位置
- 改为按深度层进行平衡采样
- 让不同深度层在训练集和测试集中都具有可比的样本量

这样做是为了避免一个统计偏差：

- 外层电阻天然数量更多
- 若不平衡采样，可能只是“样本更多所以更容易学”，而不是真正的“物理上更容易识别”

### 五、建议输出

该子项目建议固定输出以下图表：

- `4x4`：外层 / 内层 的 `ID` 与 `Value` 对比图
- `5x5`：外层 / 内层 的 `ID` 与 `Value` 对比图
- 综合图：
  - 横轴为深度层
  - 纵轴为 `ID exact rate`
  - 分别画出 `4x4` 与 `5x5`

若正式版完成，再额外输出：

- 平衡采样后的深度分层数据表
- 不同深度层对应的 `ID / Value` 精确数值图

### 六、当前执行顺序

当前执行顺序固定为：

1. 先在现有 `4x4`、`5x5`、`K=1` 结果上做按深度分层的快速统计
2. 若已有结果已经显示明显趋势，再生成平衡采样版正式数据
3. 若 `4x4` 与 `5x5` 都支持同一规律，再考虑扩展到 `6x6`
4. 只有在 `K=1` 的深度规律明确之后，才考虑扩展到 `K=2`

### 七、当前口径

本子项目的当前正式口径为：

- 它不是重新研究规模效应
- 也不是重新研究候选电阻总数效应

## 2026-05-06 新增：理论框架验证子项目

新增目录：`theory_validation/`

该子项目用于验证老师提出的“候选可变电阻响应矩阵秩 / 奇异值”理论框架。核心思想是：

- 固定拓扑、端口、候选电阻池；
- 对每条候选电阻分别施加小扰动；
- 计算外部响应变化向量；
- 将这些向量拼成 Jacobian / 灵敏度矩阵；
- 用秩、奇异值谱、条件数和响应相似度判断候选池是否更容易重构；
- 再用同一个 `modelg2` 训练验证理论指标是否能预测 `ID exact rate` 和 `K_max`。

当前默认设置：

- 网络规模：`4x4`
- 端口：全部边界端口
- 候选池大小：`8, 12, 16, 20, 24`
- 候选池策略：随机、外侧优先、内侧优先、低相似度优先、SVD 贪心优化
- 固定变化数量：后续云端验证先取 `K=1,2,3,4`

该子项目与主线关系：

- 前四个子任务主要是观察实验；
- `theory_validation` 尝试把观察结果转化为可计算判断框架；
- 若理论指标更好的候选池在神经网络中也表现更好，则可以说明：候选池设计能够由物理可辨识性指标指导，而不是只靠经验试错。
