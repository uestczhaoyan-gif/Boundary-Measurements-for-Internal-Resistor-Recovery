# `square_scale_study` 计划书

## 总体目标

`square_scale_study` 是与已冻结 `gnn` 主线解耦的独立子项目。它只研究一个问题：

**在固定正方形拓扑下，最大可识别同时变化电阻数量 `K_max` 如何随端口数/规模变化？**

主线研究设定为：

- 只使用正方形网格：`3x3` 到 `10x10`
- 每个数据集固定变化数量 `K`
- 只研究回归，不做数量分类
- 不加噪声
- 变化电阻位置随机
- 电阻变化范围为 `±20%`

主结果曲线定义为：

- 横轴：端口数 `P = 4N - 4`
- 纵轴：最大可识别变化数量 `K_max`

## 第一阶段：固定问题定义与判据

固定设定如下：

- 拓扑：正方形 `N x N`，其中 `N = 3, 4, 5, 6, 7, 8, 9, 10`
- 节点数：`N^2`
- 电阻边数：`M = 2N(N - 1)`
- 端口数：`P = 4N - 4`
- 每个数据集固定一个 `K`
- 不混合不同 `K` 训练
- 不做变化数量分类
- 基准电阻：`R0 = 1000 Ω`
- 不加入测量噪声
- 每个样本中的变化边随机抽取且不重复
- 默认激励方式：沿顺时针边界节点做相邻循环激励，总激励数等于 `P`

通过判据固定为两项，同时满足才算“可识别”：

- `id` 判据：样本级精确 support 恢复率 `>= 0.98`
- 数值判据：
  - `value_accuracy = max(0, 1 - MAE_changed / (0.2 * R0))`
  - 阈值 `>= 0.90`

定义：

- `K_max(N)` 表示在规模 `N` 下，测试集同时满足上述两项判据的最大 `K`

## 第二阶段：建立固定 `K` 数据生成器

新数据集不再复用旧项目里混合 `0/1/2/3` 变化数量的格式。

生成规则：

- 每个 `(N, K)` 都有独立数据集
- 每个样本恰好包含 `K` 条变化电阻
- 变化边从全部电阻边中随机采样
- 变化值按 `R = R0 * (1 + δ)` 采样，其中 `δ` 在 `[-0.2, 0) ∪ (0, 0.2]` 上均匀分布
- 每个样本都在默认全边界激励集合下直接解基尔霍夫方程
- 基线电压由全 `R0` 网络求得，再相减形成电压扰动
- 图输入保持四类节点特征：
  - source mask
  - ground mask
  - 边界电压扰动
  - 边界节点 mask

默认数据划分：

- train: `8000`
- val: `1000`
- test: `1000`

命名规则：

- `data/N3x3/`, `data/N4x4/`, ..., `data/N10x10/`
- 每个数据集保存为：
  - `square_N3x3_K1_train.csv`
  - `square_N3x3_K1_val.csv`
  - `square_N3x3_K1_test.csv`
  - `square_N3x3_K1_meta.json`

## 第三阶段：最简回归主线

第一版模型刻意保持简单。

固定模型/训练设定：

- 只做回归
- 复用当前 GNN 主线的基本思想：
  - 每个激励图内做消息传递
  - 跨激励做注意力池化
  - 最后输出边级回归值
- 不使用 mask head
- 不使用门控
- 不输出候选集
- 不使用 BCE、稀疏正则或对比损失
- 第一版损失为 `SmoothL1Loss(pred, target)`
- 推理时按 `|pred|` 选择前 `K` 条边

checkpoint 排序规则：

1. `val_id_exact_rate`
2. `val_value_accuracy`
3. `-val_mae_changed`

每个 epoch 至少保留：

- `train_id_exact_rate`
- `train_value_accuracy`
- `val_id_exact_rate`
- `val_value_accuracy`
- `val_mae_changed`

## 第四阶段：扫描 `(N, K)` 得到主曲线

主线扫表策略：

- 对每个 `N`，从 `K = 1` 开始
- 每个 `(N, K)` 都独立生成、独立训练、独立推理
- 若测试集满足：
  - `test_id_exact_rate >= 0.98`
  - `test_value_accuracy >= 0.90`
  则记为通过，并继续测试 `K + 1`
- 某个 `K` 首次失败后，再多测一个 `K`
- 连续两个 `K` 失败后，停止该规模扫描
- 最后一个通过的 `K` 记为 `K_max`

每个 `(N, K)` 都必须保留：

- 训练侧：
  - `train_id_exact_rate`
  - `train_value_accuracy`
- 推理侧：
  - `test_id_exact_rate`
  - `test_value_accuracy`
- 辅助信息：
  - `val_id_exact_rate`
  - `val_value_accuracy`
  - `test_mae_changed`
  - `pass_flag`

必须输出：

- 明细表：每个 `(N, K)` 的训练/验证/测试指标
- 汇总表：`N`、`P`、`M`、`K_max` 及对应测试指标
- 主图：
  - `N` vs `K_max`
  - `P` vs `K_max`

## 第五阶段：多激励研究（主工作之后）

这一阶段明确后置，只有在主曲线稳定后才进入。

研究问题：

- 多激励组合是否真的增加了可用信息通道数？
- 还是主要提升了数值精度和稳定性？

代表性规模：

- `N = 4, 7, 10`
- 每个规模选：
  - `K = K_max(N) - 1`
  - `K = K_max(N)`

要比较的激励子集：

- `1`
- `2`
- `4`
- `8`
- `full`

数值分析输出：

- `test_id_exact_rate`
- `test_value_accuracy`
- `test_mae_changed`
- `K_max` 是否改变

物理分析输出：

- 响应矩阵秩 / 有效秩
- 奇异值谱
- 条件数
- 不同激励集合下的响应相似性 / 相干性

结论判据：

- 若激励数增加导致 `K_max` 上升，说明其提升了可辨识信息
- 若 `K_max` 不变但误差下降，说明其主要提升了精度或稳定性
- 若两者同时发生，则需分开报告“信息增益”和“稳定化效应”

## 当前迭代策略

- 旧 `gnn` 主线保持冻结，不再在旧目录上继续扩展新逻辑
- 根目录长文档不继续增长，本项目细节全部沉淀在 `square_scale_study/` 内
- 当前模型改进优先在 `3x3` 网络上做快速迭代
- 只有当 `3x3` 上出现清晰、可重复的提升后，才扩展到 `4x4`、`5x5` 及更大规模
- 这样做的目的是缩短单次模型修改周期，减少云端资源消耗，并更快定位“结构变化是否真的有效”

## 输出与验收标准

子项目需要稳定产出的内容包括：

- 每个 `(N, K)` 的数据元信息
- 每个 `(N, K)` 的训练/验证/测试指标
- 全局 sweep 明细 CSV
- `port count - K_max` 汇总 CSV
- 可直接用于汇报的图和表

主线完成的验收标准：

- `N = 3..10` 都完成扫描
- 每个规模都有明确 `K_max`
- 每个 `(N, K)` 都保存训练与推理两侧指标
- `P - K_max` 曲线可复现、可解释、可用于汇报
- 第五阶段不是主线完成的前置条件

## 默认说明

- 第一轮基线刻意不用门控
- 若最简基线过早失效，门控、稀疏先验、候选集输出等再作为第二轮增强方向
- `id` 通过阈值默认固定为 `0.98`
- `value_accuracy` 阈值默认固定为 `0.90`
